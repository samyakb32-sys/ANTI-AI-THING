# Assignment Rewriter

Rewrites your own assignment drafts into a more natural, personal tone — keeps facts, arguments, and structure intact.

## Setup

```bash
npm install
export ANTHROPIC_API_KEY=your_key_here
npm start
```

Open http://localhost:3000

## Usage

Paste text or upload a `.txt`, `.md`, `.docx`, or `.pdf` file, pick a tone, and click Rewrite.

## Note

This tool is meant for editing your own work into your own voice. It does not fabricate content — it only rewrites what you provide. Always follow your school or institution's policy on AI-assisted writing.
